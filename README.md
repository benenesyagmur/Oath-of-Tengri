Oath of Tengri

An original survival roguelike inspired by Turkic mythology, ancient Anatolia, and the spirit of the steppe.

Project Status

Phase: Research and Pre-Production

Game development has not started yet. The current focus is gameplay analysis, technical investigation, and original game design.

Originality

Oath of Tengri will have its own identity, original assets, characters, world, content, and implementation.

Repository Structure

research/ — Analysis reports, evidence, and technical findings

docs/ — Research summaries, design notes, and future game documentation

The structure may evolve as the project progresses.
