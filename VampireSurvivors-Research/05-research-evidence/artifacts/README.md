# Kanıt Artifaktları

Bu klasör, izin verildiğinde yeniden üretilebilir, türetilmiş kanıt dosyalarını (ör. ekran görüntüsü, zaman çizelgesi CSV'si, REA dışa aktarım demeti) saklar.

İlk oturumda orijinal oyun varlığı veya ikilisinin kopyası alınmadı. REA kimlikleri [kanıt dizininde](../evidence-index.md) tutulur.
